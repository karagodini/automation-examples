# Мониторинг цен каталога

Скрипт обходит каталог [books.toscrape.com](https://books.toscrape.com/catalogue/page-1.html), сохраняет название, цену, наличие и рейтинг в Excel и CSV и сравнивает срез с прошлым снимком. Новые товары и изменившиеся цены уходят в Telegram. Рейтинг сам по себе уведомление не вызывает.

Запуск из этой папки (зависимости ставятся из корня репозитория):

```bash
cd price-monitor
python -m price_monitor.main --max-pages 1 --delay 0
```

Полезные флаги: `--url`, `--max-pages`, `--data-dir`, `--delay`, `--timeout`. Токен Telegram читается только из окружения, чтобы не оставаться в истории команд.

## Переменные

Их можно положить в `.env` в корне репозитория. Полный список — в [`.env.example`](../.env.example).

| Переменная | Зачем |
| --- | --- |
| `CATALOGUE_URL` | Первая страница. По умолчанию `.../catalogue/page-1.html` |
| `MAX_PAGES` | Сколько страниц обойти. В песочнице их 50, для пробы хватает 1–2 |
| `REQUEST_DELAY` | Пауза между страницами, секунды. По умолчанию 0.4 |
| `DATA_DIR` | Куда класть файлы. По умолчанию `price-monitor/data` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Куда слать сводку. Пустые — печать в консоль |

На ответ 429 или 5xx и на обрыв сети запрос повторяется до трёх раз, с паузой между попытками. В каждый запрос подставляется свой User-Agent.

## Файлы

- `data/catalogue.xlsx` — лист «Каталог»: шапка, фильтр, закреплённая первая строка, ширина колонок, цена числом;
- `data/catalogue.csv` — те же колонки, UTF-8 с BOM;
- `data/snapshot.json` — прошлый снимок для сравнения.

Колонки: Название, Цена, Валюта, Наличие, В наличии (`да`/`нет`), Рейтинг (1–5), Ссылка.

Первый запуск записывает файлы и снимок и не шлёт уведомление: сравнивать ещё не с чем. Если Telegram ответил ошибкой, снимок не обновляется, и следующий запуск повторит ту же сводку. Позиции, которые пропали из каталога, пишутся в лог и в сообщение не попадают.

Пример сводки — в [корневом README](../README.md#примеры-вывода).

## Тесты

Из корня репозитория: `pytest price-monitor/tests`. HTML каталога лежит в `tests/fixtures/`, сеть для разбора страницы не нужна. Отдельно проверяются пагинация, ретраи и User-Agent у сессии, diff снимка и запись Excel.
